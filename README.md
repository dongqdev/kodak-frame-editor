# kodak-frame-editor

코닥 디지털 액자에 **이메일로 사진을 보내기 전에**, 브라우저에서 액자 화면 비율(16:10)에 맞춰
미리 잘라주는 웹 도구.

코닥 액자는 `<액자번호>@mx1.kodakframes.com` 주소로 이메일을 보내면 사진이 올라간다. 그런데
폰으로 찍은 사진은 대부분 3:4나 9:16이라 액자 화면(16:10)과 비율이 안 맞고, 그대로 보내면
액자가 알아서 자르거나 늘여서 이상하게 나온다. 이 도구는 **보내기 전에** 어디를 보여줄지
직접 정하게 해준다.

## 이 도구가 해결하는 것

- **비율 안 맞음**: 액자 비율에 맞춰 미리 자른다. 어디를 살릴지 드래그로 직접 고른다.
- **잘리는 게 싫을 때**: 축소해서 남는 자리를 배경색으로 채운다. 배경색은 사진 가장자리에서
  자동으로 뽑아준다.
- **인생네컷처럼 좁고 긴 사진**: 자동으로 감지해서, 자르지 않고 통째로 좌우에 나란히(오른쪽은
  거울 반전) 배치한다.
- **여러 장 한꺼번에**: 최대 30장까지 편집하고 한 번에 보낸다. 액자가 한 통에 너무 많은
  첨부를 처리하지 못하므로 자동으로 여러 통으로 나눠 발송한다.
- **액자 화면 흐림**: 액자 패널 해상도(긴 변 1920px)에 맞춰 미리 고품질로 축소해서 보낸다.
  액자 내장 스케일러에 맡기는 것보다 선명하다.
- **HEIC**: 아이폰 HEIC 사진을 브라우저에서 자동 변환한다.

사진 처리는 전부 브라우저 안에서 일어난다. 서버는 완성된 결과물을 받아 이메일로 보내기만 한다.

## 흐름

1. 사진 여러 장 선택 (HEIC 포함)
2. 사진마다 액자 프레임에 자동으로 채워 넣고, 세 가지 방식으로 조정:
   - **자유**: 드래그로 위치, 휠/핀치로 확대·축소 (프레임보다 작게 줄이면 빈 자리는 배경색)
   - **높이 맞춤**: 높이를 프레임에 고정하고 좌우로만 드래그
   - **너비 맞춤**: 너비를 프레임에 고정하고 상하로만 드래그
3. 미리보기 화면에서 전체 확인 (썸네일을 누르면 확대 + 그 사진으로 바로 재편집)
4. 액자 번호를 입력하고 전송

## 직접 띄우기

```bash
npm install
cp .env.example .env    # 아래 항목들을 채운다
npm start               # 기본 포트 8003
```

`.env`에 필요한 값:

| 변수                              | 설명                                                                  |
| --------------------------------- | --------------------------------------------------------------------- |
| `SMTP_SERVER`, `SMTP_PORT`        | 발신 SMTP 서버 (Gmail이면 `smtp.gmail.com` / `587`)                   |
| `SENDER_EMAIL`, `SENDER_PASSWORD` | 발신 계정. Gmail은 계정 비밀번호가 아니라 **앱 비밀번호**를 써야 한다 |
| `FRAME_EMAIL`                     | (선택) 액자 번호를 입력받지 못했을 때 쓸 기본 수신 주소               |
| `MAIL_BATCH_MAX_BYTES`            | 이메일 한 통당 첨부 용량 상한 (기본 20MB)                             |
| `MAIL_BATCH_MAX_COUNT`            | 이메일 한 통당 첨부 장수 상한 (기본 9장)                              |
| `RATE_LIMIT_PHOTOS_PER_DAY`       | IP당 하루 발송 장수 상한 (기본 300)                                   |
| `R2_*`                            | (선택) Cloudflare R2 백업. 안 넣으면 백업만 실패하고 발송은 정상 진행 |

### 받는 주소는 왜 숫자만 입력받나

로그인이 없는 앱에서 받는 주소를 통째로 입력받으면 **아무 데나 이미지를 보내주는 공개 스팸
발송기**가 된다. 그 발송은 설정한 SMTP 계정으로 나가므로 계정이 정지될 수 있다.

그래서 도메인(`mx1.kodakframes.com`)은 서버 상수로 박아두고 사용자에게는 `@` 앞 숫자만
받는다. 검증으로 막는 게 아니라 **코닥 액자 밖으로는 구조적으로 보낼 수 없게** 만든 것이다.
직접 띄워서 쓸 때도 이 부분은 그대로 두는 걸 권한다.

## 만든 것

Vanilla JS + Express. 프레임워크 없음. 브라우저에서 [Cropper.js](https://fengyuanchen.github.io/cropperjs/)와
[heic2any](https://github.com/alexcorvi/heic2any), 서버에서 [nodemailer](https://nodemailer.com/)를 쓴다.
